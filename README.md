# REACT JS Checkpoint — GOMYCODE

Premier contact avec React : une application créée avec **create-react-app** et stylée avec **react-bootstrap**.

## Contenu

- Le dossier `src` ne garde que `index.js` et `reportWebVitals.js`, plus le nouveau composant `App.js`.
- `App` renvoie un **fragment React** (`<>...</>`) qui contient un `div` avec la classe `App`.
- Dans ce `div`, des composants react-bootstrap :
  - une **barre de navigation** (`Navbar`, `Nav`) ;
  - un **en-tête** (`header`) ;
  - **3 cartes** (`Card`), générées à partir d'un tableau avec `map()`.

## Lancer le projet

```bash
npm install
npm start
```

L'application s'ouvre sur http://localhost:3000.

## Technologies

React · react-bootstrap · Bootstrap 5 · create-react-app
